ORB means Object Request Broker. It is a middleware technology that enables communication between distributed objects in a distributed system. An ORB-based system typically uses a language-independent Interface Definition Language (IDL) to define the interface of the objects.

The communication works like this:

1. A client object sends a request to the ORB. The ORB delivers the request to the correct server object.
2. The ORB uses the IDL interface of the object to marshal the request parameters. This puts them in a format that the network can transmit.
3. The ORB sends the request to the location of the server object.
4. The ORB on the server side unmarshals the request parameters. It passes them to the server object.
5. The server object processes the request. It sends a response to the client object through the ORB.
6. The ORB on the client side unmarshals the response parameters. It passes them to the client object.

Objects communicate as if they are in the same address space. This is true if they are on different machines or use different programming languages. IDL gives platform and language independence. Objects in different programming languages communicate without problems.

ORB communication lets distributed objects interact in a distributed system. It is a powerful tool to build complex, distributed applications.
