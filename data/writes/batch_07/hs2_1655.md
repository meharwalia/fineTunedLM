To cross build the TPM2 Software Stack libraries to ARM 64bit:

1. Install a cross compiler that supports the ARM 64bit architecture. Download the ARM cross compiler from the GCC website.
2. Set up the environment variables for the cross compiler. This tells the build system to use the cross compiler instead of the default compiler.
3. Download the TPM2 Software Stack from the TPM2 website. Extract it to a directory of your choice.
4. Run the configure script to set up the build system. Specify the path to the cross compiler and the target architecture. For example:
```
./configure --host=arm64-linux --prefix=/usr
```
5. Build the libraries with the make command:
```
make
```
6. Install the libraries with the make install command:
```
make install
```
7. Test the build with the test scripts:
```
make test
```

These steps are a general guide. They can differ slightly, depending on the version and configuration of the TPM2 Software Stack. For more detailed instructions, refer to the documentation and README files for your version of the stack.
