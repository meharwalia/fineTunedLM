Interactive Deepening Depth-First Search (IDDFS) is a variation of the Depth-First Search (DFS) algorithm in graph theory and computer science. It finds a solution to a problem. It explores the search tree depth-first.

IDDFS also increases the search depth dynamically during the search. This is "interactive deepening".

IDDFS runs a depth-first search to a set depth. If it does not find the goal state, it increases the search depth. It then repeats the search. It repeats this process until it finds the goal state or the search depth exceeds a set limit.

**Complexity**

- Time complexity: O(b^d). b is the branching factor of the search tree. d is the depth of the search. The time to search the tree increases exponentially with the depth of the search.
- Space complexity: O(bd). This represents the number of nodes that the search explores.

**Parameters**

- Starting depth: the initial depth at which the search begins.
- Increment value: the amount by which the search depth increases each time the goal state is not found.

The choice of parameters is important. It affects the time and space complexity of the algorithm.

A larger starting depth and a smaller increment value can give a more efficient search. The algorithm explores a larger part of the search tree in less time. This can also give a larger space complexity, because the search explores more nodes.

A smaller starting depth and a larger increment value can give a less efficient search. It can take longer to find the goal state.

Base the choice of parameters on the specific problem and the available resources, such as time and memory. The goal is a balance. The search explores enough of the search tree to find the goal state.

The time and space complexity stay within reasonable limits.
