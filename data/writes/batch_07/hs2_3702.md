To show your Fargate console logs in CloudWatch, configure your task to use the AmazonCloudWatchLogDriver. This driver publishes container logs to CloudWatch Logs.

1. Open the Amazon ECS console at https://console.aws.amazon.com/ecs/.
2. Select the cluster that has the task definition to update.
3. Choose Task definitions in the navigation panel.
4. Select the task definition to update.
5. Choose the Register button.
6. In the Log configuration section, select Amazon CloudWatch Logs from the drop-down menu.
7. Choose the Amazon CloudWatch log group for your task.
8. Choose the Register button to save the changes to your task definition.

When you run a task with this task definition, the container logs go to the specified CloudWatch log group. To view the logs, open the CloudWatch console. Select Logs in the navigation panel.
