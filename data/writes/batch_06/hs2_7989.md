To autogenerate for Java OpenAPI, build a custom pipeline and deploy its output to Artifactory. Follow these steps:

1. Create a custom pipeline: Create it in Jenkins or any other continuous integration tool. It handles the autogeneration process.
2. Set up the tools: Install the OpenAPI tools, such as the OpenAPI Java generator, on the build server. Download them from the OpenAPI website or install them with a package manager like Maven or Gradle.
3. Define the OpenAPI specification: Define the specification for your API in a YAML or JSON file. The file must contain all the necessary information about your API, including the endpoints, request and response formats, and authentication information.
4. Run the OpenAPI generator: Run the generator on your build server. It takes the OpenAPI specification as input. It generates Java classes and interfaces that represent your API's endpoints and data models.
5. Deploy to Artifactory: Deploy the generated Java code to an Artifactory repository for easy access by your developers. Use a tool like Maven or Gradle to publish the code to the repository.
6. Test and refine: Test the generated and deployed code to make sure it works as expected. You may need to refine the OpenAPI specification or change the generated code to meet your requirements.

These steps autogenerate Java code for your OpenAPI API with a custom pipeline and deploy it to Artifactory.
