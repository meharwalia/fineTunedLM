**Purpose of normalization**

Normalization organizes the data in a database. Its main purpose is to minimize redundancy in a relation or set of relations. It also reduces insertion, update, and deletion anomalies.

**First normal form (1NF)**

1NF is the basic level of normalization. Its purpose is to eliminate repeating groups and store related data together. A relation is in 1NF if it has no repeating groups and all data is in a single table.

For example, a customer database has the fields name, address, phone number, and email. To store multiple phone numbers for each customer, create a separate table with the fields customer_id and phone_number.

This avoids storing the same information multiple times in one table. It keeps the data consistent.
