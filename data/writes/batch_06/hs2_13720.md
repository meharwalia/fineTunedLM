Yes, you can check if two Excel files have the same records. Follow these steps:

1. Open both Excel files.
2. Make sure the data is in the same format and in the same order in both files. If necessary, sort the data by the relevant columns.
3. In one of the files, select the range of data to compare.
4. Go to the "Formulas" tab in the Excel ribbon. Click "Define Name" in the "Named Cells" group.
5. In the "New Name" dialog box, give the selected range a name (for example, "Data1").
6. Repeat steps 3-5 for the second file. Give the range a different name (for example, "Data2").
7. In a new sheet in either file, enter this formula in a blank cell:

   ```
   =COUNTIF(Data1, Data2)
   ```

   Replace "Data1" and "Data2" with the names from steps 5 and 6.
8. Press Enter. The result is the number of records that are in both files.
9. To see which records are in both files, use the "VLOOKUP" function. This is an example formula:

   ```
   =IFERROR(VLOOKUP(A2, Data2, 1, FALSE), "Not Found")
   ```

   Replace "A2" with the cell reference of the first record to compare. Replace "Data2" with the name of the range in the second file. Change the column number (here, "1") to the column of the matching records.
10. Drag the formula down to compare all records in the first file with the records in the second file. If a record is in both files, the formula shows the matching record. If the record is not in the second file, the formula shows "Not Found".
