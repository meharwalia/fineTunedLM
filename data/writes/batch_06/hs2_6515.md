Follow these steps to diagnose why the engine of your 1997 Jeep Wrangler does not fire on any cylinder:

1. Check for spark: Disconnect one spark plug wire. Attach a spark tester to the wire. Have an assistant crank the engine. Watch the spark tester. If there is no spark, the problem can be the ignition coil, ignition module, crank sensor, or spark plug wires.
2. Check for fuel: Disconnect the fuel line at the fuel rail. Put a container under the fuel line to catch leaking fuel. Have an assistant crank the engine. Watch for fuel coming out of the fuel line. If there is no fuel, the problem can be the fuel pump, fuel pump relay, fuel pump fuse, or fuel injectors.
3. Check for compression: Use a compression tester on each cylinder. Low compression in any cylinder can show a damaged piston, piston ring, or valve.
4. Check for engine codes: You said that the OBD-2 port shows no codes. Still, use a scan tool to check for codes stored in the engine control module (ECM).
5. Check for a clogged fuel filter: Do this if the fuel pump works and there is fuel in the fuel rail, but the engine does not start. Check the fuel filter. Replace it if necessary.
6. Check the mass airflow (MAF) sensor: It measures the amount of air that enters the engine. It sends this information to the ECM. A faulty MAF sensor can cause the engine to not fire properly. Check the sensor. Replace it if necessary.
7. Check the camshaft position (CMP) sensor: It measures the position of the camshaft. It sends this information to the ECM. A faulty CMP sensor can cause the engine to not fire properly. Check the sensor. Replace it if necessary.
8. Check the crankshaft position (CPS) sensor: It measures the position of the crankshaft. It sends this information to the ECM. A faulty CPS sensor can cause the engine to not fire properly. Check the sensor. Replace it if necessary.

If you check all of these components and still cannot find the problem, take the vehicle to a qualified mechanic for diagnosis and repair.
