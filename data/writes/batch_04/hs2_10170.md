iptables is a user-space utility program. A system administrator uses it to configure the IP packet filter rules of the Linux kernel firewall.

Different Netfilter modules implement these rules. Use these steps:

1. Check the current rules before you configure iptables. Run `sudo iptables -L -v`.
2. To block a specific IP address, run `sudo iptables -A INPUT -s <IP address> -j DROP`. Replace `<IP address>` with the IP address to block.
3. To allow traffic on a specific port, run `sudo iptables -A INPUT -p tcp --dport <port number> -j ACCEPT`. Replace `<port number>` with the port number to allow.
4. To block all incoming traffic, run `sudo iptables -P INPUT DROP`.
5. To allow all outgoing traffic, run `sudo iptables -P OUTPUT ACCEPT`.
6. Save your rules so that they stay after a reboot. The command depends on your Linux distribution. For Ubuntu and Debian, run `sudo /sbin/iptables-save`.

**Warning:** Use `iptables` commands with caution. Incorrect configuration can lock you out of your system. Make a backup of your current rules before you make changes.
