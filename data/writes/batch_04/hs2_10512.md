SMART on FHIR is an open source platform. It lets healthcare applications access and interact with electronic health record (EHR) systems through the FHIR standard. Its components work together as follows.

**Components**

- **FHIR Server:** The core component. It stores and retrieves patient data from the EHR system. It conforms to the FHIR specification and has a RESTful API for patient data.
- **SMART Platform:** The client-side component. It authenticates users, authorizes access to patient data, and interacts with the FHIR server to retrieve and display patient data. It also has tools and libraries for development of healthcare applications.
- **Application Developer:** This component develops healthcare applications that access patient data through the platform. Developers use the SMART platform tools and libraries.
- **User:** This component uses the healthcare applications to access patient data. The SMART platform authenticates users. It authorizes access to patient data based on role and permissions.

**Interaction**

1. A user opens a healthcare application built on the SMART on FHIR platform.
2. The application uses the SMART platform to authenticate the user and get an access token.
3. The application uses the access token to request patient data from the FHIR server.
4. The FHIR server sends the requested patient data. The application shows it to the user.
5. To add or update data, the user interacts with the patient data. The application then sends requests to the FHIR server with the access token.

The platform lets healthcare applications access patient data in EHR systems through the FHIR standard. Its components are a FHIR server, a SMART platform, application developers, and users.
