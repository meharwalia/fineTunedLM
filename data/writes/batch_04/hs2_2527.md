When you add existing users from Active Directory to Microsoft Dynamics, Dynamics fills in these fields automatically:

- User Name
- First Name
- Last Name
- Email Address
- Department
- Title
- Phone Number
- Mobile Phone Number
- Fax Number
- Street Address
- City
- State/Province
- Postal Code
- Country/Region

Not all of these fields exist in every Dynamics implementation. Some depend on the specific Active Directory attributes that map to the Dynamics user object.
