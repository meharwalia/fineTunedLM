Question: Sally invited 8 friends to her birthday party and ordered 3 peperoni pizzas for them to share. If each pizza is cut into 6 slices, how many slices will there be for each friend?

Reasoning:

1. Find the total number of slices.
2. There are 3 pizzas. Each pizza has 6 slices.
3. Multiply the number of pizzas by the number of slices per pizza: 3 pizzas * 6 slices/pizza = 18 slices.
4. Determine the number of slices each friend gets.
5. Sally invited 8 friends. Divide the total number of slices by the number of friends: 18 slices / 8 friends = 2.25 slices.

Answer: Each friend gets 2.25 slices. A fraction of a slice is not possible.

So each friend gets 2 slices, with 6 slices remaining. You can distribute the remaining slices among the friends or save them for later.
