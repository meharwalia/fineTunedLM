The three main space allocation methods for storing files on disks are contiguous allocation, linked allocation and indexed allocation. Each method has advantages and disadvantages. Each supports different types of file access.

1. **Contiguous allocation:** Each file occupies a contiguous address space on disk. The blocks of a file are in a continuous sequence. This method supports sequential and direct access. Sequential access is fast because the blocks follow one another. Direct access is also fast. The disk head moves quickly to the block with the starting address of the file and the block size. The method can cause external fragmentation and inefficient disk space use.
2. **Linked allocation:** Each file is a linked list of disk blocks. The blocks can be anywhere on the disk. Each block has a pointer to the next block in the file. This method supports sequential access but not direct access. Sequential access is straightforward because the blocks link together. Direct access is slow because the disk head must follow the pointers to find the block. This method suits large files with sequential access, such as video files.
3. **Indexed allocation:** Each file has an index block with pointers to the disk blocks of the file. The index block is small. The system stores it separately from the data blocks of the file. This method supports sequential and direct access. Direct access is fast because the disk head moves quickly to the block through the index block. The method can be inefficient for small files. The overhead of the index block can be larger than the file.

A hybrid method, extent-based allocation, also exists. It divides files into large chunks called extents. Each extent is a contiguous sequence of blocks.

The file system keeps a table that maps each extent to its physical location on the disk. This method supports sequential and direct access. It suits large files with random access.

It minimizes the number of disk head movements needed to access the blocks of the file.

The choice of method depends on the type of file access you need:

- Contiguous allocation is best for small files with random access.
- Linked allocation is best for large files with sequential access.
- Indexed allocation is best for small to medium-sized files with random access.
- Extent-based allocation is a hybrid method for large files with random access.
