A Windows workstation remembers a server connection after disconnection through a "net use" mapping. A net use mapping establishes a network connection between a client and a server. The registry of the client computer stores it.

When a user connects to a server, the client computer stores the connection information in the registry. This includes the server name, share name, username and password. The client uses this information to establish a network connection the next time the user logs in.

If the physical connection between the client and the server is lost, the net use mapping stays in the registry. The client computer reconnects to the server automatically the next time it connects to the network.

The user can then access the server resources. The user does not need to enter the connection information again.

The net use mapping is specific to the client computer and the user who established the connection. If multiple users need the same server resources, each user must establish their own net use mapping.
