In graph theory, forward propagation is a technique to solve color problems. A color problem is the assignment of colors to the vertices of a graph. No two adjacent vertices can have the same color.

Forward propagation is a greedy algorithm. It starts by assigning a color to a vertex. Then it propagates the color to all adjacent vertices.

The algorithm repeats the process for each uncolored vertex. It always chooses the color with the fewest adjacent vertices that already have a color.

The algorithm continues until all vertices have a color. It also stops if it cannot find a color that satisfies the constraints of the problem.

In that case, the algorithm fails to find a valid solution. The problem is "unsolvable".

Forward propagation is a simple and efficient algorithm for color problems. People often use it as a baseline to compare more sophisticated algorithms.

However, it may not find the optimal solution. It may sometimes get stuck in a local minimum.

**Example**

The graph has six vertices and seven edges. The goal is a valid coloring of the vertices with three colors (red, blue and green). The graph:

```
V1 V2 V3 V4 V5 V6
V1 -- -- -- -- -- --
V2 -- X -- -- -- --
V3 -- -- X -- -- --
V4 -- -- -- X -- --
V5 -- -- -- -- X --
V6 -- -- -- -- -- X
```

The algorithm starts with an uncolored vertex, such as V1. It assigns a color to V1, such as red. It propagates the color to all vertices adjacent to V1, here V2 and V5.

Then it repeats the process for each uncolored vertex. It always chooses the color with the fewest adjacent vertices that already have a color.

The algorithm continues until all vertices have a color, or until no color satisfies the constraints. Here, the algorithm finds a valid coloring of the vertices with three colors:

```
V1 V2 V3 V4 V5 V6
V1 R -- -- -- -- --
V2 B X -- -- -- --
V3 G -- X -- -- --
V4 G -- -- X -- --
V5 G -- -- -- X --
V6 G -- -- -- -- X
```

In this example, forward propagation finds a valid coloring with three colors.
