Apache Kafka is a popular open-source streaming platform. To stream real estate data in Apache Kafka:

1. Install Kafka. Download Apache Kafka and install it on your machine. The official Kafka website has the instructions.
2. Create a Kafka cluster. A Kafka cluster has one or more servers that store and process data. You can create it on your local machine or on a remote server.
3. Create a topic. Kafka organizes data into topics. A topic is a collection of messages about the same subject. Create a topic for your real estate data.
4. Produce data. Write a program or script that produces real estate data. It publishes the data to the topic you created. Use the Kafka producer API to publish data to the topic.
5. Consume data. Write another program or script. It consumes the data from the Kafka topic. It stores the data in a database or performs another action. Use the Kafka consumer API to consume data from the topic.
6. Configure Kafka. Set Kafka to suit your needs. For example, set the number of replicas, the retention time for messages or the size of the message batch.

These are the basic steps. Kafka is a powerful and flexible platform. It can stream different types of data.
