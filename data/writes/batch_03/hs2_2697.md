To adapt an open-source Chrome extension, such as ShareGPT, to a Safari extension on iOS:

1. Download the source code of the Chrome extension.
2. Identify the core function that you want to port to Safari. Review the code and documentation of the extension.
3. Make sure that the Safari extension format meets the requirements of the core function. Safari extensions are WebKit extension objects. They must follow specific guidelines.
4. Create a new project in Xcode. Add the necessary files from the source code of the Chrome extension to the Safari extension project. You may need to convert the code to the Safari extension format. You may also need to make modifications for compatibility.
5. Test the Safari extension on an iOS device or simulator. Make sure that it works as you expect.
6. Submit the Safari extension to the App Store for distribution.

Apple's review process and guidelines apply to extensions for iOS. Read them before you submit your extension.

Also respect the terms of the license of the open-source Chrome extension. Make sure that your adaptations follow its requirements.
