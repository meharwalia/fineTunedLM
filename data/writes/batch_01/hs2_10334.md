These are the key entities and their relationships for a shipping system:

1. **Customer:** A customer places orders and can have multiple orders. A customer can have one or more addresses.
2. **Order:** An order belongs to a customer. It can have multiple order items. It has one shipping address and one billing address.
3. **Order Item:** An order item belongs to an order. It has one product.
4. **Product:** A product can have multiple order items.
5. **Address:** An address belongs to a customer, to an order as a shipping address, or to an order as a billing address.
6. **Shipping Party:** A shipping party is an external party that ships an order. An order has one shipping party.
7. **Invoice:** An invoice belongs to an order. It can have multiple invoice items.
8. **Invoice Item:** An invoice item belongs to an invoice. It has one order item.
9. **Return:** A return belongs to an order. It can have multiple return items.
10. **Return Item:** A return item belongs to a return. It has one order item.
11. **Loyalty Program:** A loyalty program can have multiple customers. A customer has one loyalty program.
12. **Rating:** A rating belongs to a customer. It can go to another customer or to a shipping party.

Use these entities and relationships to create an Entity Relationship Diagram (ERD). The shipping system keeps data on accounts with loyalty and user ratings, invoicing, returns and external shipping parties.
