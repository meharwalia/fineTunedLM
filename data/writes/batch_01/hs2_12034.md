This example applies Proper Orthogonal Decomposition (POD) to a simple numerical dataset.

**Data**

The dataset has three vectors in 2D space:

x1 = [1, 2]
x2 = [3, 4]
x3 = [5, 6]

Put the vectors in the columns of a matrix X:

X = [x1, x2, x3] = [1, 3, 5; 2, 4, 6]

**Steps**

1. Compute the mean of the dataset:

   mean(X) = (1+3+5)/3, (2+4+6)/3 = [3, 4]

2. Subtract the mean from each vector. This gives the mean-centered dataset:

   X_centered = X - mean(X) = [-2, -1, 2; -2, 0, 2]

3. Compute the covariance matrix of the mean-centered dataset:

   C = X_centered' * X_centered = [4, 4; 4, 4]

4. Find the eigenvalues and eigenvectors of the covariance matrix:

   eigenvalues = [8, 0]
   eigenvectors = [[1/sqrt(2), 1/sqrt(2)]; [-1/sqrt(2), 1/sqrt(2)]]

5. Take the POD modes. The POD modes are the eigenvectors of the covariance matrix.
6. Compute the POD coefficients. They are the projections of the mean-centered dataset onto the POD modes:

   a = X_centered * eigenvectors = [-2, -2; -1, 1; 2, 2]

7. Reconstruct the original dataset from the POD modes and coefficients:

   X_reconstructed = mean(X) + a * eigenvectors' = [1, 3, 5; 2, 4, 6]

This is a simple example of POD on a 2D dataset.
