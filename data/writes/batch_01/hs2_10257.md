Authentication and authorization are two fundamental concepts in information security. They have different purposes.

**Authentication**

Authentication verifies the identity of a user, device or system. The user usually gives credentials, such as a username and password. The credentials confirm that the user is who they claim to be.

Multi-factor authentication (MFA) is another form. It needs more verification from the user, such as a fingerprint or a code sent to a mobile device.

**Authorization**

Authorization grants or denies access to specific resources or actions. It uses the identity and permissions of the user. After authentication, the system uses authorization to decide what the user can do.

For example, an authenticated user can view certain files or folders. The user cannot modify or delete them.

Authentication verifies identity. Authorization grants or denies access based on that verified identity.
