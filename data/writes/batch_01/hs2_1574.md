**A1:** Object-oriented programming (OOP) is a programming paradigm. It divides all the logic of a program into objects. Objects hold data (attributes) and procedures (methods).

This models the real world more naturally. Objects interact with each other through messages.

The need for an object-oriented approach comes from the wish to create maintainable and scalable software.

OOP creates reusable components. You can combine them to create complex systems.

OOP also gives a clear separation of concerns.

This makes the code easier to understand and modify.
