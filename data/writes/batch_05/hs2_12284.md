Garbage collection is automatic memory management in the Go programming language. It reclaims memory that a program no longer uses.

The Go garbage collector is a concurrent, tri-color mark-and-sweep collector. It runs in parallel with the program. It marks each object in memory as reachable or unreachable. It keeps reachable objects in memory. It treats unreachable objects as garbage and can free them.

The Go garbage collector is efficient. It minimizes the effect on program performance. It is also incremental. It runs in small steps, not all at once. This avoids long pauses in the program execution.

The garbage collector is on by default and runs automatically. You do not call it or manage memory yourself. You can control its behavior to a limited degree with the GOGC environment variable. This variable sets the target percentage of memory growth between garbage collections.

The garbage collector makes Go programs more efficient and easier to write. It manages memory automatically and frees resources that the program no longer needs.
