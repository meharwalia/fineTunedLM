Hypertext Markup Language (HTML) is the standard markup language for web pages and web applications. It is a system of tags (also called elements) and attributes. They describe the structure and content of a web page. HTML lets you create and organize text, images, videos, and forms on a web page.

A web browser reads the HTML tags and attributes. It uses the tags to decide how to structure and show the content, such as headings, paragraphs, and lists. Attributes give more information about the elements, such as their style, size, and behavior.

HTML documents have a .html or .htm file extension. To view one, enter the file URL or location in a web browser. HTML is often used with CSS (Cascading Style Sheets) and JavaScript. Together they make web pages that are more complex and dynamic.

This is an example of a simple HTML document:

```html
<!DOCTYPE html>
<html>
  <head>
    <title>My Web Page</title>
  </head>
  <body>
    <h1>Welcome to my web page</h1>
    <p>This is my first web page!</p>
  </body>
</html>
```

In this example:

- The `<html>` tag marks the start of the HTML document. The `</html>` tag marks the end.
- The `<head>` tag contains information about the document, such as the title.
- The `<body>` tag contains the content that the page shows.
- The `<h1>` tag creates a large, centered heading.
- The `<p>` tag creates a paragraph of text.
