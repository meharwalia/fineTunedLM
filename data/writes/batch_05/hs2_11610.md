To declare an array as an input in an HTML form:

1. Use the `<input>` element.
2. Set the "name" attribute to the name of the array.
3. Add square brackets [] after the name. They show that it is an array.

For example:

```html
<input type="text" name="myArray[]">
```

This creates an input field for a single value. To let the user enter more than one value, add more `<input>` elements with the same "name" attribute:

```html
<input type="text" name="myArray[]">
<input type="text" name="myArray[]">
<input type="text" name="myArray[]">
```

When the user submits the form, the browser sends the values in these input fields to the server as an array with the name "myArray".

You can also use other input types, such as "checkbox", "radio", or "select", to create arrays in HTML forms. Use the same "name" attribute with square brackets. The specific input type determines the values.
