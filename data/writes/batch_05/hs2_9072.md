**Definitions**

- **Interrupt:** A signal from a peripheral device or other hardware component to the processor. It shows that the processor must give attention. The interrupt pauses the current activity of the processor. The processor then handles the request from the device.
- **Vector interrupt:** An interrupt that has a unique memory address, called an interrupt vector. The interrupt vector points to the memory location of the interrupt service routine (ISR). When a vector interrupt occurs, the processor uses the vector to find the ISR. Then the processor runs the ISR instructions to handle the request.
- **Non-vector interrupt:** An interrupt that has no unique memory address or interrupt vector. It typically uses a fixed set of hardware registers to store the interrupt information. The processor reads these registers to find the source of the interrupt. Then it starts to handle the request.

**Difference between vector and non-vector interrupts**

| Parameter | Vector Interrupt | Non-Vector Interrupt |
| --------- | ---------------- | -------------------- |
| Identification | Has a unique memory address (interrupt vector) | Has no unique memory address |
| Processing | The processor uses the interrupt vector to find the interrupt service routine (ISR) | The processor reads a fixed set of hardware registers to find the source of the interrupt |
| Efficiency | Typically more efficient. The interrupt vector gives faster processing | Typically less efficient. The processor must read hardware registers to find the source |
| Complexity | More complex to set up and manage. You must manage interrupt vectors and ISRs | Simpler to set up and manage. You do not manage interrupt vectors |
