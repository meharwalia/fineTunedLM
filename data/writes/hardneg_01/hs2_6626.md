**System Programming and Operating Systems**

- System programming is a field of computer science that deals with the development of software that directly interacts with the hardware of a computer system, and it essentially includes writing code that controls the CPU, manages memory and storage, and handles input and output devices.
- An operating system is a type of software that manages the hardware and software resources of a computer, and it acts as an interface between the user and the computer, by which the computer is allowed to be interacted with in a way that is easy and intuitive.
- It is important to note that tasks such as managing files, running applications, controlling the use of memory and processing power, and handling input and output from devices such as keyboards, mice, and displays are performed by the operating system.
- In an easy-to-understand way, the operating system can be thought of as the "middle man" between the user and the computer hardware, since all of the technical details are taken care of so that the computer can be utilised by the user in order to accomplish their tasks.
