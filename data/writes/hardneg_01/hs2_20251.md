**Recommended Actions for the Web Application Infrastructure**

1. It should be noted that the PostgreSQL database should be migrated to Amazon Aurora, which is a fully-managed relational database engine that provides high availability and scalable performance, and it is designed to be compatible with PostgreSQL, which makes it an ideal choice for the database migration of the company.
2. The web application should be migrated to be hosted on AWS Fargate with Amazon ECS, since AWS Fargate is a serverless compute engine that allows containers to be run without servers or clusters having to be managed, and automatic scaling and reduced operational overhead can be benefited from by the company when the containers are managed by Amazon ECS.
3. In addition, it may be considered that an Amazon CloudFront distribution is set up for the web application content, because Amazon CloudFront is a content delivery network (CDN) that can facilitate improved performance and availability by caching content at edge locations around the world.
4. An Amazon ElastiCache is also set up between the web application and the PostgreSQL database, which is a fully-managed in-memory data store that can facilitate improved performance and scalability by caching frequently accessed data.
5. By these changes being implemented, the infrastructure of the web application can be improved, operational overhead can be reduced, and future growth can be supported by the company.
