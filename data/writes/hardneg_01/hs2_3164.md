**Why I/O Instructions Are Privileged**

- It should be noted that these instructions are privileged because serious harm can potentially be caused if they are executed in user mode by an unprivileged user.
- For example, a device that they should not have access to could be written to by a user, which can subsequently result in data loss or system instability.
- By these instructions being kept in kernel mode, it can be ensured by the operating system that I/O devices are accessed only by authorized users, and that sufficient stability and security of the system are maintained.
