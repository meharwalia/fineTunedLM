**Dockerfile for Ubuntu 22.04 with Nginx and a Sample index.html**

- It should be noted that an Ubuntu 22.04-based Docker image with the latest version of Nginx and a sample index.html file with a random Wikipedia page is created by the following Dockerfile, in which various packages are installed and the files are subsequently copied.

```
# Use the latest version of Ubuntu 22.04 as the base image
FROM ubuntu:22.04

# Set the default command to run when the container starts
CMD ["/bin/bash"]

# Install Nginx and other necessary packages
RUN apt-get update && apt-get install -y nginx nginx-full && rm -rf /var/lib/apt/lists/*

# Create a new directory for the website content
RUN mkdir /usr/share/nginx/html

# Copy a sample index.html file into the website content directory
COPY index.html /usr/share/nginx/html/

# Start Nginx when the container starts
CMD ["/usr/sbin/nginx", "-g", "daemon off;"]

# Expose port 80 to allow access to the website from outside the container
EXPOSE 80
```

- The index.html file that is copied into the website content directory is shown below, and it is dynamically generated by utilising the Docker image and displays a random Wikipedia page.

```
<!DOCTYPE html>
<html>
<head>
  <title>Random Wikipedia Page</title>
</head>
<body>
  <h1>Random Wikipedia Page</h1>
  <p>This page is dynamically generated by the Docker image and displays a random Wikipedia page.</p>
  <p>To access the page, visit <a href="http://localhost/">http://localhost/</a> in your web browser.</p>
</body>
</html>
```

- In order to build the image, the Dockerfile and index.html file should be saved in the same directory and the following command is run, by which the image is built with the tag "my-nginx-image": `docker build -t my-nginx-image .`
- The image is run and the sample website is accessed by the following command, which essentially starts the Nginx server in the container and maps port 80 on the host machine to port 80 in the container, and the website can then be accessed by visiting http://localhost/ in a web browser: `docker run -p 80:80 my-nginx-image`
