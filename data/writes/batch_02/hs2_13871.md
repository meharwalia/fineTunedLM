LTI Advantage, LTI 1.3, and deep linking are three related concepts in online learning.

**Definitions**

- LTI Advantage: a set of standards that lets learning tools interoperate with learning management systems (LMS) and other education technology platforms. It makes it easier for educators to use and integrate third-party tools in their teaching and learning environments. It builds on earlier versions of the LTI standard.
- LTI 1.3: the latest version of the Learning Tools Interoperability (LTI) standard. The standard lets learning tools and platforms communicate with each other. LTI 1.3 adds new features, such as support for open authorization (OAuth), more flexible tool launching, and better security.
- Deep linking: a technique that lets users go to specific content in an application or website, not the homepage or main menu. In online learning, a deep link can go directly to a specific lesson, quiz, or other learning material in an LMS or other learning platform. Deep linking improves the user experience. Learners do not need to search or navigate through multiple pages to find content.

**Overlap**

- LTI Advantage and LTI 1.3: LTI Advantage builds on LTI 1.3. LTI 1.3 is the core standard. It provides the technology for communication between learning tools and platforms. LTI Advantage adds capabilities that improve the integration experience.
- Deep linking and LTI: Deep linking can work with LTI for smoother integration between learning tools and platforms. When a user launches a tool with LTI, the user can go directly to the specific content or activity in the learning platform. The user does not navigate there manually.
- Deep linking with LTI Advantage and LTI 1.3: Deep linking improves the user experience and simplifies navigation within a learning platform. Learners go directly to the content or activity they need, without multiple pages or menu levels. This saves time and makes learning more efficient and effective.
