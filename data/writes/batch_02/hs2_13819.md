To build a web app that makes interactive summaries of tweets with a keyword, you need to learn programming and web development. Follow these steps:

1. Learn HTML, CSS, and JavaScript. These are the basic technologies for web applications. HTML structures the content. CSS styles it. JavaScript adds interactivity.
2. Learn a web framework. A framework simplifies the process. As a beginner, start with a JavaScript framework such as React or Vue.js.
3. Learn to use APIs. You need Twitter's API to access Twitter data. Learn to make HTTP requests and parse JSON data.
4. Learn to visualize data. Libraries such as D3.js or Chart.js can help you make charts and graphs.
5. Learn to deploy your app. After you build it, deploy it to a web server. Services such as Heroku or Netlify can deploy your app easily.

These resources can help you start:

- Codecademy: offers free courses on HTML, CSS, JavaScript, and web frameworks.
- Twitter API documentation: explains how to use Twitter's API.
- D3.js documentation: explains how to visualize data with D3.js.
- Heroku documentation: explains how to deploy your app to Heroku.

Building a web app is a complex task. It needs time and effort. Keep learning and practicing, and you can build the app you want.
