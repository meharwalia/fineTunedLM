To configure your user name and email address in Git, run these commands in your terminal or command prompt:

```
git config --global user.name "Your Name"
git config --EMAIL@EXAMPLE.COM
```

In the commands:

- Replace "Your Name" with your actual name.
- Replace "EMAIL@EXAMPLE.COM" with your actual email address.

The --global option sets these configurations for all repositories on your system. To set them for a specific repository, omit the --global option. Run the commands from within the repository directory.

After you set these configurations, Git uses them to attribute commits and other actions to you.
