Use the `help()` function or the `dir()` function to view the functions in a Python module in the command prompt (cmd).

**Use help()**

1. Open the command prompt.
2. Go to the directory that holds the module.
3. Type `help(module_name)`. Press Enter. Replace `module_name` with the name of the module.
4. Read the output. The command prompt shows a list of all the functions in the module, with a brief description of each function.

For example, type `help(math)`. Press Enter. The command prompt shows the functions in the `math` module, such as `acos`, `asin`, `atan`, and others.

**Use dir()**

1. Open the command prompt.
2. Go to the directory that holds the module.
3. Type `dir(module_name)`. Press Enter. Replace `module_name` with the name of the module.
4. Read the output. The command prompt shows a list of all the functions in the module.

For example, type `dir(math)`. Press Enter. The command prompt shows the functions in the `math` module, such as `acos`, `asin`, `atan`, and others.

The `help()` and `dir()` functions also work with built-in Python modules, such as `math` and `sys`.
