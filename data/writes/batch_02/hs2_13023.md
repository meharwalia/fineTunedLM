Subtotal consolidation is a feature in Microsoft Excel. It summarizes and consolidates data from multiple worksheets or workbooks into a single worksheet. It is useful when you have a large amount of data to analyze and summarize in a single location.

To use subtotal consolidation in Excel:

1. Open the workbook that contains the data you want to consolidate.
2. Select the worksheets that contain the data you want to consolidate.
3. Click the Data tab on the ribbon.
4. Click the Consolidate button in the Function Library group.
5. In the Function box, select the function to summarize the data (for example, Sum, Average, or Count).
6. In the Reference box, select the range of cells that contain the data you want to consolidate.
7. Click Add to add the reference to the All references box.
8. Repeat steps 6 and 7 for each worksheet you want to consolidate.
9. Click OK to consolidate the data.

Excel creates a new worksheet with the consolidated data and subtotals for each group of data. Use this worksheet to analyze and summarize the data.

You can also use the Subtotal feature in Excel to summarize data within a single worksheet. This feature groups and summarizes data by specific criteria, such as date or product category.
