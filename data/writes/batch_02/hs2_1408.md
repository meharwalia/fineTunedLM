To hook up Active Campaign to Heap, follow these steps:

1. In Heap, create a new event for each event you want to track in Active Campaign. For example, to track when a user signs up for a free trial, create an event called "Sign Up for Free Trial."
2. In Active Campaign, create a new automation. Set it to trigger when the "Sign Up for Free Trial" event occurs in Heap.
3. In the automation, create a new action. Set it to send an email to the user who signed up for the free trial.
4. Test the automation to make sure it works correctly.
5. Repeat steps 1 to 4 for each other event you want to track in Active Campaign.

Now the events you track in Heap trigger automated emails in Active Campaign.
