Here is an example agenda for family nightly planning:

1. **Dinner:** Discuss what is for dinner. Decide who prepares it.
2. **Homework:** Ask each family member if they have homework. Help them if needed.
3. **Chores:** Assign chores for the next day. Make sure everyone knows their responsibilities.
4. **Calendar:** Review the family calendar. Make sure everyone knows about upcoming events or activities.
5. **Family time:** Set aside time to do something fun together. Play a game, watch a movie, or go for a walk.
6. **Bedtime:** Set a reasonable bedtime for each family member. Make sure everyone is ready for a good night's sleep.
