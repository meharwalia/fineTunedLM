Use this security group layout:

1. Create a global group in Domain A. Add users from Domain A to this group.
2. Create a global group in Domain B. Add users from Domain B to this group.
3. Create a domain local group in Domain A. Add the global groups from Domain A and Domain B as members.

Users from both domains can then access resources in Domain A. They must be members of the correct global group. The domain local group in Domain A must have the necessary permissions.

Follow these steps to implement the layout:

**1. Create a global group in Domain A**

- Open Active Directory Users and Computers.
- Right-click the domain name. Select New, then select Group.
- Enter a name for the group (e.g., AppAccessA).
- Select Global Group as the group type.

**2. Create a global group in Domain B**

- Open Active Directory Users and Computers.
- Right-click the domain name. Select New, then select Group.
- Enter a name for the group (e.g., AppAccessB).
- Select Global Group as the group type.

**3. Add users to the global groups**

- In Domain A, add users from Domain A to the AppAccessA group.
- In Domain B, add users from Domain B to the AppAccessB group.

**4. Create a domain local group in Domain A**

- Open Active Directory Users and Computers.
- Right-click the domain name. Select New, then select Group.
- Enter a name for the group (e.g., AppAccess).
- Select Domain Local Group as the group type.

**5. Add the global groups to the domain local group**

- Right-click the AppAccess group. Select Properties.
- Go to the Members tab.
- Click Add. Select the AppAccessA and AppAccessB groups from the correct domain.
- Click OK to add the groups as members of the AppAccess group.

**6. Set the necessary permissions on the domain local group**

- Right-click the AppAccess group. Select Properties.
- Go to the Security tab.
- Add the necessary permissions for the AppAccess group to access the resources in Domain A.
- Click OK to save the changes.
