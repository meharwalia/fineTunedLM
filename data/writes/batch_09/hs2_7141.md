Establishing performance measurement for a function or process that runs on software involves seven steps:

1. **Define the objectives.** Define the objectives of the function or process. Examples are to improve response time, reduce memory usage, or increase the number of transactions processed per second.
2. **Identify key performance indicators (KPIs).** Choose the KPIs that measure performance. If the objective is to improve response time, the KPIs can be average response time, 95th percentile response time, and maximum response time.
3. **Collect data.** Collect data on the function or process. Use tools such as performance counters, logging, or distributed tracing.
4. **Analyze data.** Analyze the data to find bottlenecks or areas to improve. Use tools such as charts, graphs, or dashboards to visualize the data.
5. **Set targets.** Use the data analysis to set targets for the KPIs. Targets must be realistic and achievable. They must align with the objectives of the function or process.
6. **Monitor performance.** Monitor performance regularly to check that the function or process meets the targets. Use tools such as alerts, notifications, or automated testing.
7. **Take action.** If performance does not meet the targets, address the issue. Change the code, adjust the configuration, or add resources.

These steps help you find areas to improve. They also help you check that the function or process meets its performance targets. This leads to a more efficient and effective software system.
