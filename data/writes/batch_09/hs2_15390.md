J Perm PLL is an algorithm that solves the last layer of a Rubik's Cube. Many PLL algorithms exist. The easiest one for a beginner depends on the individual learning style and the speed the beginner wants to reach. This J Perm PLL algorithm can be easy for a beginner to learn:

x R' U R' D2 R U' R' D2 R2 x'

The letters show the movement of the layers from the natural holding position:

* R - Right side clockwise [Right side upwards]
* R’ - Right side anticlockwise [Right side downwards]
* D - Bottom layer clockwise
* D’ - Bottom layer anticlockwise
* x - Rotate the entire cube on the R axis towards you
* x’ - Rotate the entire cube away from you
* U - Upper face clockwise
* U’ - Upper face anticlockwise

For more algorithms and a visual aid with a step-by-step guide, use this link: https://www.speedcubedb.com/a/3x3/PLL/Aa/0

This algorithm uses only eleven moves. It is relatively straightforward. Practice it slowly at first. Focus on the correct finger movements. Make sure you execute each move precisely. With practice, you can perform the algorithm quickly. You can then solve the cube in a matter of seconds.
