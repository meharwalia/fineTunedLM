If b is a spatial part of c, and c is a spatial part of d, then b is a spatial part of d.

The relationship is hierarchical. The part b sits inside d. The part c is the intermediate component between b and d.

You can write this as b ⊂ c ⊂ d. The symbol "⊂" shows that b is a proper part of c, and that c is a proper part of d.

Example: a room is a spatial part of a house. A table is a spatial part of the room. The table is then a spatial part of the house, because the room places it inside the house.
