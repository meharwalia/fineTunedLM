Here are 10 questions for a multiple-choice test to screen for machine learning skills:

1. In binary classification using logistic regression, the objective is to predict the probability of belonging to which of the two classes?
2. In gradient boosted decision trees (GBDT), the base learners are decision trees. They are fitted on the negative gradient of the loss function. Which of the following loss functions is typically used in GBDT for binary classification?
3. It is common to one-hot encode categorical variables in machine learning. Which of the following is a disadvantage of one-hot encoding?
4. In classification, accuracy is a common metric to evaluate the performance of a model. Which of the following is another important metric that is often used in addition to accuracy?
5. In binary classification, recall and precision are two metrics that evaluate the performance of a model. Which of the following is a disadvantage of using precision as the sole metric for evaluation?
6. In linear regression, the goal is to find the best fitting line for a set of data points. Which of the following is an advantage of using linear regression over other types of regression models?
7. In least squares regression, you minimize the error between the predicted and actual values by finding the coefficients of the linear model. Which of the following is an advantage of using least squares regression over other methods of regression?
8. Feature selection is an important step in pre-processing data in machine learning. Which of the following is an advantage of using feature selection techniques?
9. Principal component analysis (PCA) is a technique in unsupervised learning that reduces the dimensionality of a dataset. Which of the following is a disadvantage of using PCA?
10. In clustering, k-means is a popular algorithm that groups data points into k clusters. Which of the following is a requirement for using k-means clustering?

Note: These questions give a basic overview of the key concepts in machine learning. They are not exhaustive. Also consider questions specific to the topics you want to test.
