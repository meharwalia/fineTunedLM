Virtual memory is a memory management technique of operating systems. It lets a process use more memory than the system physically has.

The operating system creates a virtual address space that is larger than the physical address space. It maps the virtual addresses to physical addresses as needed.

When a process accesses a memory location that is not in physical memory, the operating system swaps a portion of physical memory out to disk. This frees room for the requested memory.

This process is paging. The portion that the operating system swaps out is a page.

**Example**

1. A process requests a memory location that is not in physical memory.
2. The operating system looks at the virtual address space. It finds the page that holds the requested memory.
3. The page is not in physical memory. The operating system swaps a different page out to disk to make room.
4. The operating system loads the requested page into physical memory.
5. The process accesses the memory location as if it was always in physical memory.

Virtual memory makes more efficient use of physical memory. Multiple processes share the same physical memory.

Larger programs also run on systems with limited physical memory. The operating system swaps pages out to disk to make room for new pages.
