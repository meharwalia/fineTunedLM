**User steps**

1. The new user gets an email invitation to create a Google Workspace account.
2. The user clicks the invitation link and creates a password.
3. The user sets up MFA. This needs the Google Authenticator app on their smartphone.
4. The user scans the QR code on the screen with the Google Authenticator app. The user enters the verification code that the app generates.
5. The user completes the setup. The user can then access the account with their email address, their password, and the verification code from the Google Authenticator app.

**Administrator steps**

1. The administrator creates a new user account in the Google Admin console.
2. The administrator assigns a license to the account.
3. The administrator enables MFA for the account. Select the "2-step verification" option in the Admin console.
4. The administrator sends the new user an email invitation to set up the account.
5. The administrator monitors the account setup and MFA enrollment in the Admin console.
6. After the user completes the setup and enrolls in MFA, the administrator can give the user training and support. This helps the user start with Google Workspace.
