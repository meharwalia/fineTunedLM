To sync Kafka and OneSignal, follow these steps:

1. Set up a Kafka cluster. Kafka is a distributed messaging system. It lets you publish and subscribe to messages. Use an existing cluster or set up a new one.
2. Connect Kafka to OneSignal. OneSignal is a push notification service for mobile devices. Use a tool such as Apache NiFi or a custom-built solution.
3. Publish a message to Kafka when the asynchronous request pattern data is available. The message contains the data and a unique identifier.
4. Subscribe the front-end client to the Kafka topic. The client listens for messages that contain the unique identifier.
5. Send a notification to OneSignal when the front-end client receives a message from Kafka. Use the unique identifier.
6. OneSignal delivers the notification to the correct devices. The user learns that the data is available.

With this approach, the front-end client gets a notification when the data is available. You do not need to poll the server for updates. This improves the user experience and reduces the load on your server.
