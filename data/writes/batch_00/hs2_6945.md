This is a script for a half-hour training on GA4 website vital statistics.

1. Introduction to GA4
   - Review the purpose of GA4.
   - Review the differences between GA4 and Universal Analytics.
   - Explain why client services must understand website vital statistics.
2. Understanding GA4 reports
   - Review the reports in GA4 and the purpose of each report.
   - Show how to open the reports.
   - Show how to move between the reports.
3. Understanding website traffic
   - Review the key traffic metrics: sessions, users, and pageviews.
   - Show how to read the data.
   - Show how to find trends over time.
4. Understanding user behavior
   - Review the key behavior metrics: bounce rate, average session duration, and pages per session.
   - Show how to use this data to measure user engagement.
   - Show how to use this data to find areas for improvement.
5. Comparing GA4 and Universal Analytics data
   - Review the differences in data collection methods.
   - Review the differences in available metrics.
   - Show how to compare the data to find trends and discrepancies.
6. Conclusion
   - Recap the key points of the training.
   - Give the team time for questions and discussion.

Use examples and visuals to explain the concepts and data. Good luck with your training.
