Hadoop is an open-source framework for distributed storage and processing of large datasets. It handles datasets that do not fit in the memory of one machine. It processes them efficiently across the machines in a cluster.

These are the most common Hadoop applications:

1. **MapReduce:** A programming model that processes large datasets in parallel on a cluster. It does data processing tasks such as data analysis, data mining, and data aggregation.
2. **HDFS (Hadoop Distributed File System):** A distributed file system that stores large amounts of data across the machines in a cluster. It gives high bandwidth for reading and writing data. This makes it ideal for data storage and retrieval.
3. **Hive:** A data warehouse system. It gives a SQL-like interface to query and analyze large datasets stored in HDFS.
4. **Pig:** A high-level data flow language that processes large datasets in parallel on a cluster. It does data analysis, data transformation, and data loading.
5. **HBase:** A distributed, non-relational database. It gives real-time access to large datasets stored in HDFS. It does real-time data storage and retrieval.
6. **ZooKeeper:** A distributed coordination service. It gives naming, configuration, and synchronization services to other Hadoop components.

These applications are examples of the applications that run on the Hadoop framework. Hadoop is a flexible and extensible platform for data processing and storage tasks.
