This Dockerfile creates an Ubuntu 22.04 Docker image with the latest Nginx and a sample index.html file with a random Wikipedia page.

```
# Use the latest version of Ubuntu 22.04 as the base image
FROM ubuntu:22.04

# Set the default command to run when the container starts
CMD ["/bin/bash"]

# Install Nginx and other necessary packages
RUN apt-get update && apt-get install -y nginx nginx-full && rm -rf /var/lib/apt/lists/*

# Create a new directory for the website content
RUN mkdir /usr/share/nginx/html

# Copy a sample index.html file into the website content directory
COPY index.html /usr/share/nginx/html/

# Start Nginx when the container starts
CMD ["/usr/sbin/nginx", "-g", "daemon off;"]

# Expose port 80 to allow access to the website from outside the container
EXPOSE 80
```

This is the index.html file that the Dockerfile copies into the website content directory:

```
<!DOCTYPE html>
<html>
<head>
  <title>Random Wikipedia Page</title>
</head>
<body>
  <h1>Random Wikipedia Page</h1>
  <p>This page is dynamically generated by the Docker image and displays a random Wikipedia page.</p>
  <p>To access the page, visit <a href="http://localhost/">http://localhost/</a> in your web browser.</p>
</body>
</html>
```

To build the Docker image:

1. Save the Dockerfile and the index.html file in the same directory.
2. Run this command:

```
docker build -t my-nginx-image .
```

This builds the Docker image with the tag "my-nginx-image".

To run the image:

```
docker run -p 80:80 my-nginx-image
```

This starts the Nginx server in the Docker container. It maps port 80 on the host machine to port 80 in the container. Visit http://localhost/ in your web browser to see the sample website.
