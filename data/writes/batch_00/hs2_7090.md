This is a road map to learn AI and Machine Learning if you have no computer science background.

1. **Start with the basics.** Build a strong foundation in computer science and programming. Learn the basics of programming: syntax, data types, variables, and control structures. You can start with any programming language. Python is a popular choice for AI and Machine Learning.
2. **Learn the fundamentals of AI and Machine Learning.** Learn the types of AI and Machine Learning algorithms, such as supervised and unsupervised learning. Learn how they work. Free online courses and tutorials can help you start.
3. **Get hands-on experience.** The best way to learn is by doing. Implement algorithms and models on your own with publicly available datasets. This helps you understand the concepts. It also shows you what it is like to work with AI and Machine Learning in practice.
4. **Stay up-to-date.** AI and Machine Learning evolve rapidly. Follow industry leaders and experts on social media. Read blogs and articles. Attend conferences and workshops.
5. **Practice, practice, practice.** Work on projects and challenges. Do not be afraid to make mistakes. Learn from your mistakes and keep practicing.
6. **Build a portfolio.** Start a portfolio of your work as you progress. It shows your skills to potential employers and clients. It also lets you reflect on your progress.
7. **Stay curious and keep learning.** The field of AI and Machine Learning is vast and complex. Explore new areas and topics. This helps you become an AI and Machine Learning expert.

**Books**

- "Introduction to Machine Learning with Python" by Andreas C. Müller and Sarah Guido
- "Python Deep Learning Bible" by Peter Harrington
- "Machine Learning: A Algorithmic Perspective" by Stephen Marsland
- "The Hundred-Page Machine Learning Book" by Andriy Burkov
- "AI: A Modern Approach" by Stuart J. Russell and Peter Norvig

**Courses**

- "Machine Learning Crash Course" by Google
- "Machine Learning with Python" by DataCamp
- "Intro to Machine Learning" by Stanford University
- "Machine Learning" by Harvard University
- "Artificial Intelligence" by MIT

**Online resources**

- "Kaggle": a platform for data science competitions and projects
- "TensorFlow": an open-source machine learning library
- "PyTorch": an open-source machine learning library
- "Scikit-Learn": a popular machine learning library for Python
- "PyData": a community for data scientists and Python enthusiasts
