Use the =TITLE() function in Google Sheets. It extracts the title from the URL in a cell.

If the URL is in cell A1, use this formula:

```
=TITLE(A1)
```

The formula returns the title of the page at the URL in cell A1.

The =TITLE() function reads the <title> tag of the HTML document. It may not return the most relevant or descriptive title for the page. In that case, edit the title manually or use a different method to extract the information from the URL.
