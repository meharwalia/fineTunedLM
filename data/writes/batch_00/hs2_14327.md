A webhook lets one website or application send information to another in real time. The systems communicate without manual data entry or polling.

**How a webhook works**

1. The first system sets up a webhook. It gives a URL where it wants to receive data.
2. An event occurs in the first system, for example a new comment on a blog post. The system sends a POST request to the URL.
3. The POST request contains data about the event, such as the content of the new comment.
4. The receiving system processes the data. It takes the appropriate action, such as showing the new comment on a blog post.

**Common uses**

- **Real-time notifications:** Send notifications to users or systems when events occur. Examples are a new comment on a blog post or a new order in an online store.
- **Data synchronization:** Keep data in sync between systems. An example is an update to a customer database when a customer places an order in an online store.
- **Third-party integration:** Connect to third-party services. Examples are data to a marketing automation tool for a new lead, or data to a payment gateway for a new order.

Webhooks help real-time communication between systems. They can also streamline business processes.
