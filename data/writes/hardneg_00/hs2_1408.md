**Connecting Active Campaign to Heap**

To hook up Active Campaign to Heap, the steps below can be followed, and it should be noted that they are performed in order to allow the events that are tracked in Heap to be utilised for automated emails.

1. A new event is created in Heap for each event that is to be tracked in Active Campaign, and for example an event called "Sign Up for Free Trial" is created if the signing up of a user for a free trial is to be tracked.
2. A new automation is created in Active Campaign that is triggered when the "Sign Up for Free Trial" event occurs in Heap.
3. A new action is created in the automation by which an email is sent to the user who signed up for the free trial.
4. The automation is tested to make sure that it is working correctly.
5. Steps 1 to 4 are repeated for any other events that are to be tracked in Active Campaign.

Now the events that are tracked in Heap can be utilised to trigger automated emails in Active Campaign, and various other things can be done as well.
