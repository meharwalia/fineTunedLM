**Declaring an Array Input in an HTML Form**

An array is declared as an input in an HTML form by utilising the <input> element with the "name" attribute set to the name of the array followed by square brackets [], and it should be noted that this is performed as shown in the example below.

- A single value can be entered by the user in the following field:

```html
<input type="text" name="myArray[]">
```

- Multiple values are allowed by adding additional <input> elements with the same "name" attribute, as shown here:

```html
<input type="text" name="myArray[]">
<input type="text" name="myArray[]">
<input type="text" name="myArray[]">
```

- When the form is submitted, the values that were entered into these input fields are sent to the server as an array with the name "myArray".
- Other input types, such as "checkbox", "radio", or "select", can also be utilised to create arrays, in which case the same "name" attribute followed by square brackets is used, but the values are determined based on the specific input type.
