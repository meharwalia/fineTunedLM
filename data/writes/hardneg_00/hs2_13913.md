**ORB Communication**

ORB, which stands for Object Request Broker, is a middleware technology that enables communication between distributed objects in a distributed system, and the communication between objects is typically performed by a language-independent Interface Definition Language (IDL) being utilised to define the interface of the objects.

1. When a request is wanted to be made by a client object to a server object, the request is sent to the ORB, which is responsible for delivering it to the appropriate server object.
2. The object's IDL interface is utilised by the ORB to marshal the request parameters into a format that can be transmitted over the network, and the request is then sent to the location of the server object.
3. Once the request has arrived at the server object, the request parameters are unmarshaled by the ORB on the server side and are passed to the server object, and the request is processed by the server object.
4. A response is sent back to the client object through the ORB, and the response parameters are unmarshaled by the ORB on the client side and passed to the client object.

It is important to note that objects are allowed by this mechanism to communicate as if they were in the same address space, even if they are located on different machines or are running in different programming languages.
