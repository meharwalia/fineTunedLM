**Virtual Memory in Operating Systems**

Virtual memory is a memory management technique that is utilised by operating systems to allow a process to use more memory than is physically available in the system, and it is achieved by a virtual address space being created that is larger than the physical address space, with the virtual addresses being mapped to physical addresses as needed.

- When a memory location that is not currently in physical memory is accessed by a process, a portion of physical memory is swapped out to disk by the operating system to make room, and this is known as paging, with the swapped portion being called a page.
- **Example:** A process requests a memory location that is not currently in physical memory, the page that contains it is determined by the operating system from the virtual address space, a different page is swapped out to disk if necessary, and the requested page is then loaded so that the location can be accessed as if it were always in physical memory.
- Essentially, more efficient use of physical memory is allowed, since multiple processes can share the same physical memory.
- Larger programs can be run on systems with limited physical memory, because pages can be swapped out to disk by the operating system, and numerous other benefits are also provided.
